# Support

Public beta support is provided through GitHub Issues:

<https://github.com/ontheoasis13/My-WhiteBoard/issues>

## Before opening an issue

1. Update the marketplace and reinstall the plugin.
2. Start a new Codex task.
3. Try the same action with a new non-sensitive test board.
4. Check whether the problem is local editing, authentication, sync, sharing, Realtime, or export.

## Include

- Operating system
- Codex surface and version, if visible
- Plugin version
- Reproduction steps
- Expected and actual behavior
- Sanitized screenshots or logs

Never include credentials, API keys, email confirmation links, private board contents, or personal information.

Public beta support is best-effort and does not include uptime, recovery, or response-time guarantees.
